⚡ Connect Real Database & Email
📦 Step 1 — Supabase (Free Database) 1. Go to supabase.com → Sign in with Google
2. Create a new project
3. Go to SQL Editor → run:
create table inquiries (id uuid default gen_random_uuid() primary key, name text, email text, service text, budget text, message text, status text default 'new', created_at timestamptz default now()); 4. Settings → API → copy URL & anon key
5. Open pixelforge.html → find CONFIG at top → paste values
📧 Step 2 — EmailJS (Free Email Alerts) 1. Go to emailjs.com → Sign in with Google
2. Add Email Service → connect Gmail
3. Create Email Template — use variables:
New inquiry from {{name}} ({{email}}). Service: {{service}}. Budget: {{budget}}. Message: {{message}} 4. Account → copy Public Key
5. Open pixelforge.html → find CONFIG → paste all 3 EmailJS values
